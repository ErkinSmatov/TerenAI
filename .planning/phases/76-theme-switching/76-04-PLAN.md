Из lib/ui/getColor.ts: export default function getColor(name: ColorName, opacity?: number, theme?: ThemeName): string ("worklet").

Ключи палитры (76-01): primaryForeground — на заливке primary; accentText — тонкие линии/иконки/текст акцента на поверхности; primary — заливки площадью.

Правило подписки (единое для фазы):
- Каждый React-компонент файла, где вызывается getColor, вызывает `const { theme } = useThemeContext();` и передаёт `theme` третьим аргументом КАЖДОГО getColor.
- Модульный StyleSheet.create с getColor → модульная фабрика `createStyles(theme)` + `useThemedStyles(createStyles)`; литералы `as const`.
- Worklet/Skia: тема из React-области, передаётся явно.
- getActiveTheme не использовать.
Проверка файлов: `node scripts/checks/themeColors.check.mjs <файлы>`.
