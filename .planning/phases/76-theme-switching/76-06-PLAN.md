Из lib/ui/getColor.ts: export default function getColor(name: ColorName, opacity?: number, theme?: ThemeName): string.
Из context/ThemeContext.tsx: useThemeContext(): { theme: ThemeName; ... }.
Типичная обёртка (components/icons/micros/HealthIcon.tsx): `return <HeartPulseIcon color={getColor("health")} {...props} />;` — проп `color` из props перекрывает значение, так как `{...props}` идёт после.
Правило: в каждой обёртке `const { theme } = useThemeContext();` и `getColor(<тот же ключ>, undefined, theme)`; порядок `color={...} {...props}` сохранить. Проверка: `node scripts/checks/themeColors.check.mjs <файлы>`.
