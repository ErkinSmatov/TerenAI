<interfaces>
Из lib/ui/getColor.ts: export default function getColor(name: ColorName, opacity?: number, theme?: ThemeName): string ("worklet").
Из context/ThemeContext.tsx: useThemeContext(): { theme: ThemeName; isDark: boolean; ... }.
Из lib/ui/useThemedStyles.ts: useThemedStyles<T>(factory: (theme: ThemeName) => T): T — фабрика объявляется на уровне модуля.
Ключи палитры (76-01): primaryForeground — текст/иконки на заливке primary; accentText — акцент текстом, тонкой линией, обводкой, маленькой иконкой на поверхности base/background; primary — только заливки площадью.
Образцы: components/ui/Card.tsx (фабрика + `theme === "dark" ? 0.08 : undefined` для границы secondary), components/profile/ProfileHeader.tsx (`as const` в фабрике), app/app/(tabs)/index.tsx.

Правило подписки (единое для фазы):
- Каждый React-компонент файла (включая внутренние, например DayRow/LogRow), где вызывается getColor, сам вызывает `const { theme } = useThemeContext();` и передаёт `theme` третьим аргументом КАЖДОГО getColor (без прозрачности — `undefined` вторым).
- Модульный StyleSheet.create с getColor → модульная фабрика `const createStyles = (theme: ThemeName) => ({...})`, литеральные строковые значения (`"center"`, `"absolute"`, `"row"` и т. п.) с `as const`, в компоненте `const styles = useThemedStyles(createStyles);`. Если в файле несколько компонентов используют styles — каждый вызывает useThemedStyles(createStyles) (кэш общий). Бесцветные блоки можно оставить в отдельном модульном StyleSheet.create.
- В worklet (useAnimatedStyle/useAnimatedProps) getColor вызывается только с `theme`, полученной в React-области (комментарий в lib/ui/getColor.ts).
- getActiveTheme не использовать.
Проверка файлов: `node scripts/checks/themeColors.check.mjs <файлы>` (создана в 76-01).
