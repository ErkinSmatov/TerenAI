CustomCode (RESEARCH Open Question 4): в своём терминале, подставив свои значения в переменные оболочки, выполнить curl -s -u "$TWILIO_ACCOUNT_SID:$TWILIO_AUTH_TOKEN" "https://verify.twilio.com/v2/Services/$TWILIO_VERIFY_SERVICE_SID" и сообщить только custom_code_enabled и friendly_name. true → идём дальше. false → обращение в поддержку Twilio с просьбой включить Custom Code («ждём поддержку») или «fallback»: после этого плана /gsd:plan-phase 72 --gaps с дизайном ConvexCredentials + Twilio VerificationCheck.
