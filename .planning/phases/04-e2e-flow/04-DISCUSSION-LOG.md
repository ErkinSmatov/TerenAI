## Fix-meal UX

| Option | Description | Selected |
|--------|-------------|----------|
| await + спиннер на кнопке + Toast на ошибку | Кнопка «Исправить» показывает загрузку, пока идёт AI-запрос; при ошибке — Toast (как в auth/settings-экранах), пользователь остаётся на экране | ✓ |
| await + Toast на ошибку, без спиннера | Минимальное изменение: только правильная обработка ошибки через Toast, без визуальной индикации загрузки на время запроса | |

**User's choice:** await + спиннер на кнопке + Toast на ошибку (рекомендовано)
**Notes:** Убирает текущий баг, при котором `correctMeal(...)` вызывается без ожидания — `catch` не видит асинхронный сбой, и `router.dismiss()` срабатывает всегда, даже при ошибке AI.
