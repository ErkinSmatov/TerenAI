## Theme Tokens (light / dark)

Because this is a toggle, not a replacement, every color role below is declared for both modes. `lib/ui/getColor.ts` (or its replacement) must accept an active theme and return the matching value.

| Role | Light (existing, unchanged) | Dark (new, from Figma) |
|------|------------------------------|--------------------------|
| Background (dominant, 60%) | `#F9FAFB` | `#0A0D12` (flat; Figma's decorative radial glows are optional polish, not required for MVP of this phase) |
| Surface / card — accent | `#FFFFFF` (existing `base`) | `#272C35` |
| Surface / card — neutral | `#F3F4F6` (existing `muted`) | `#15181F` |
| Foreground (primary text) | `#030712` | `#F3F5F9` |
| Muted foreground (secondary text) | `#6B7280` | `#9299A5` / `rgba(243,245,249,0.45–0.65)` for captions |
| Accent (10%) | `#3B82F6` (existing `primary`) | `#C9F14C` (lime) |
| Destructive / over-range | `#EF4444` (existing) | `#E94545` / `#B84244` |
| Success / in-range | `#22C55E` (existing `health`) | `#869781` and lighter tints |
| Secondary/border | `#E5E7EB` (existing) | `rgba(255,255,255,0.08)` |

Accent reserved for (both themes — same reserved-for list, only the hex changes):
- Center FAB (add meal)
- Active day indicator in date selector (dashboard + Дневник chips)
- Progress fill for steps and the calorie-ring "on-track" segment
- Never used for: body text, card backgrounds, disabled states, or generic borders

Card styling (both themes, from Figma, applies to redesigned screens): radius `24px`, padding `14px` (documented exception to the 8-pt scale below — keep as-is, it is a deliberate Figma token, not a mistake), optional colored inset glow keyed to metric status (green = in range, red = over threshold) — implement as a subtle box-shadow/inset, not a full-bleed color wash.

Top "pill" elements (notification bell, streak counter): `backdrop-blur`, background `rgba(255,255,255,0.06)` dark / equivalent light tint, border `rgba(255,255,255,0.08)`, fully rounded (`999px`).

Bottom nav bar (both themes): backdrop-blur with gradient fade toward transparent at the top edge of the bar; items = icon (20px) + 12px label; center item = 64px circular accent FAB with soft colored shadow.

## Typography

Two font families, two weights each (Regular / SemiBold). Do not introduce additional weights.

| Role | Font | Size | Weight | Line Height |
|------|------|------|--------|-------------|
| Label / caption | Manrope | 12px | 400 (Regular) | 1.4 |
| Body | Manrope | 16px | 400 (Regular) | 1.5 |
| Heading | Manrope | 20px | 600 (SemiBold) | 1.2 |
| Display — metric value | Outfit | 48px | 600 (SemiBold) | 1.1 |

Screen titles reuse the Heading role (20px/SemiBold) — no separate screen-title size. The hero glucose metric (60px in Figma) and the calories total (42px in Figma) are both instances of the single Display role at its one fixed size (48px); visual weight difference between "hero" and secondary display numbers comes from layout/placement and color emphasis, not from a second display size.

Numeric values anywhere on redesigned screens (calorie totals, macro grams, glucose readings, steps) use Outfit. All non-numeric UI text (labels, buttons, section titles, body copy) uses Manrope.

## Copywriting Contract

Scope reminder: this phase is a **visual** redesign. Existing copy is preserved verbatim unless a screen's element structure actually changes (e.g. Дневник gains filter chips that didn't exist before and need new labels). Do not rewrite copy on unaffected screens.

| Element | Copy |
|---------|------|

| Дневник filter chips (new UI element per redesign) | «Все» / «Показатели» / «Питание» / «Лекарства» / «Заметки» — only include chips for data types the app actually has today (drop «Лекарства» if there is no medication-tracking feature; do not invent a feature to fill a Figma chip) |
