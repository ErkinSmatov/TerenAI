## Accomplishments

### 1. `components/home/HomeNutrientGlowCard.tsx` (new, replaces 2 old components)

A single component parameterized by `size?: "sm" | "lg"` and `darkGlowColor`/`lightGlowColor`
string props, used for all 4 tiles (3 small, 1 big "Качество"):
- No icon, no `CircularProgress` ring — just a Manrope SemiBold 12px title and an Outfit
  value/target row (20px/12px for small tiles, 48px/20px for "Качество"), matching Figma node
  813:918's structure exactly (title + number only).
- Dark theme: flat `#15181F` background + `box-shadow: inset 0 0 40px 0 <darkGlowColor>`,
  implemented via RN's `boxShadow` array with the new-architecture `inset: true` flag (verified
  present in `react-native`'s `BoxShadowValue` type — this is the first use of `inset` in this
  codebase; the existing `Card.tsx`/`getShadow.ts` boxShadow helpers only ever produce ambient,
  non-inset shadows).
- Light theme: `getColor("base", undefined, "light")` background + a soft ambient (non-inset)
  `boxShadow` at `blurRadius: 20` using `lightGlowColor` — same technique as `Card.tsx`'s
  `getGlowShadow`, adapted with new hues (see Color contract below).
- Keeps the same `Button variant="base"` wrapper the old components used (so the "Качество"
  tile's external `<Link asChild>` wrap in `HomeMicroSummary.tsx` continues to inject `onPress`
  the same way it always did) — D-04 non-interactivity behavior is unchanged.

## Color Contract (chosen values, documented per plan's request)

**Dark theme (literal, exact Figma node 813:918 match):**
- Background: `#15181F` (flat, literal hex — Figma-node pixel value)
- Клетчатка glow: `#56635E` | Сахар glow: `#C1A4BD` | Натрий glow: `#4772EB`
- All three: `inset 0 0 40px 0 <tint>` (blurRadius 40, offsetX/offsetY 0, `inset: true`)
- Качество glow: `getColor("health", undefined, "dark")` (theme-derived, not literal — the one
  approved exception)

**Light theme (Claude's Discretion — no Figma light reference exists for this node):**
- Background: `getColor("base", undefined, "light")` (existing `Card` light background token)
- Клетчатка glow: `rgba(86, 99, 94, 0.28)`
- Сахар glow: `rgba(193, 164, 189, 0.30)`
- Натрий glow: `rgba(71, 114, 235, 0.22)` — deliberately lower opacity than the other two;
  sodium's saturated blue read as a harsh outline rather than a gentle accent at the same 0.28-
  0.30 opacity used for the other two hues during review, so it was tuned down
- Качество glow: `getColor("health", 0.22, "light")` (theme-derived, matches dark variant's
  approach — 0.22 opacity chosen to sit visually between the two other tiles' opacities)
- Ambient (non-inset), `blurRadius: 20` for all four — same `boxShadow`-array technique as
  `Card.tsx`'s `getGlowShadow`, just with these new hues instead of `success`/`destructive`

Rationale for the light-theme approach (not a literal reuse of the dark look): the dark
`#15181F` flat background + inset glow reads as a deliberate near-black "chip" against the dark
`#0A0D12` screen background; the same treatment on a white/light screen would look muddy/dirty
rather than like a colored accent, so the light variant uses the lighter `base` card background
(same as every other card in the app) with a soft ambient glow at the edge instead of an inset
one — visually reads as "this card has a colored accent" rather than "this card has a dark
inset shadow," which was the goal per user_decisions #1.
