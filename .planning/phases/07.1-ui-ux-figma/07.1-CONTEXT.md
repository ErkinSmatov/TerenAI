<decisions>
## Implementation Decisions

### Порядок внедрения
- **D-01:** Редизайн внедряется поэкранно (не одним PLAN на все 5 экранов), начиная с Главной (dashboard) — это фундамент темы/шрифтов, на который опираются остальные экраны.
- **D-02:** Рекомендуемый порядок волн: Главная → Настройки/Профиль → Дневник → добавление блюда/наблюдатель. Планировщик (`gsd-planner`) может уточнить порядок внутри последних двух при построении PLAN.md, если найдёт технические причины поменять местами, но Главная всегда идёт первой.
- **D-03:** После каждой волны — остановка и подтверждение пользователем результата в приложении, прежде чем переходить к следующему экрану. Не запускать автоматическую цепочку волн без паузы, даже если верификация (build/tests) прошла чисто.

### Интерактивность графиков
- **D-04:** Кастомные Skia-графики (сахар по часам на Главной, давление, кольцо калорий) в этой фазе — чисто визуальные, без тап/протяжки для точного значения. Поведение как в Figma (статичная отрисовка). Интерактивность графиков — потенциальная отдельная будущая фаза, не часть этого редизайна.

### Claude's Discretion
- Точный порядок PLAN'ов внутри волн «Дневник» и «Добавление блюда/наблюдатель» (что раньше) — можно решить на этапе планирования по техническим зависимостям.
- Конкретная реализация переключателя темы (Context/Zustand/Convex-профиль) — решается планировщиком/исполнителем на основе текущей архитектуры `lib/ui/getColor.ts`.

</decisions>

<code_context>
## Existing Code Insights

### Reusable Assets
- `components/ui/*` (`Card.tsx`, `Button.tsx`, `Header.tsx` и др.) — существующие примитивы, которые нужно расширять на месте, не форкать параллельный набор (см. UI-SPEC).
- `lib/ui/getColor.ts` — текущий плоский цветовой резолвер, требует переработки под dual-theme (light/dark) по UI-SPEC.
- `lib/ui/resolveFontFamily.ts` — текущий резолвер шрифтов на Inter, требует замены на Manrope/Outfit.
- `@shopify/react-native-skia` — уже подключена библиотека для кастомных графиков, переиспользуется для сахара/давления/кольца калорий.
- `lucide-react-native` — уже подключённая иконочная библиотека, имена слоёв в Figma совпадают 1:1.

### Established Patterns
- Текущая навигация — 3 таба в `app/app/(tabs)/_layout.tsx` (Главная/[+]/Настройки) — редизайн сохраняет эту структуру, не добавляет новых пунктов.

### Integration Points
- Экран Дневника пересекается с историей/календарём из Phase 68/69 (`app/app/(home)/nutrients.tsx`, `app/app/(home)/day/[date].tsx`) — редизайн затрагивает именно эти файлы.

</code_context>
