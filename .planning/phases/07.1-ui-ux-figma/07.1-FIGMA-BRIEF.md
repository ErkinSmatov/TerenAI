# Figma Design Brief — Phase 07.1 (UI/UX редизайн)

Источник: https://www.figma.com/design/dGKS6NMawgiDjpvRoUp9Lv/CareAi (файл "CareAi", единственная страница "App")

**Важная оговорка от пользователя:** дизайн в Figma может расходиться с текущим приложением — часть блоков в макетах объединена иначе, чем в проде, а нижнее меню в макетах может содержать больше пунктов, чем сейчас в приложении. Это референс направления, не 1:1 спецификация. Финальный набор экранов/пунктов меню нужно сверить с REQUIREMENTS.md и текущим стеком экранов проекта, а не копировать буквально.

## Обнаруженные экраны (верхнеуровневые фреймы на странице "App")

- **Главная** — минимум 3 версии/итерации в файле (id `0:5975`, `152:5985`, `16:15121`) — похоже на эволюцию дизайна одного и того же экрана.
- **Главная (детальная, узел из ссылки пользователя, `794:563`, вложен глубже дерева)** — самая насыщенная версия дашборда: приветствие, недельный селектор дней, карусель "Недавно добавлено" (карточки блюд), график сахара (bar chart по часам), карточка "Глюкоза" (текущее значение + средн/нед + мини-график), пара карточек "Низкий/Высокий" диапазон, карточка "Калории" (кольцевой прогресс + БЖУ прогресс-бары + шаги), три карточки-плитки "Клетчатка/Сахар/Натрий", график "Давление" (line chart). Нижняя навигация: **Главная / Карты / [+ добавить приём пищи] / Советы / Профиль** (5 пунктов + центральная FAB-кнопка).
- **Дневник** (`15:13574`) — таймлайн событий по дням недели (чипы дат Пн–Вс), фильтры-чипы (Все/Показатели/Питание/Лекарства/Заметки), группировка по частям дня (Утро/День/Вечер), карточки записи сахара и приёмов пищи с фото, FAB "+" внизу справа. Нижняя навигация здесь другая: **Главная / Дневник / Обучение / Питание / Профиль**.
- **Обучение** (`15:14484`) — школа диабета: табы Видео/Статьи, горизонтальная карусель "Продолжить просмотр" с прогресс-баром, лента рекомендаций (видео-карточки с бейджами категорий), промо-блок курса "Школа диабета".
- **Профиль** (узел `136:4663`, в дереве метаданных подписан "Питание", но по скриншоту это экран Профиля — возможно расхождение имени/факта в файле, требует уточнения у дизайнера/пользователя) — аватар, статус диагноза, 3 метрики за 7 дней (сахар/время в норме/записи), блок интеграций (Apple Health, Google Fit, CGM-датчик, умные весы) со статусами подключения, секции настроек (Личные данные, Медицинские документы, Цели и напоминания, Уведомления, Единицы измерения) и поддержки, выход из аккаунта.
- Отдельный узел **Питание** (`43:276`, не изучен подробно) — вероятно отдельный от Профиля экран, имя предполагает каталог/лог питания. Требует отдельного просмотра при детальной проработке.
- Служебные фреймы дизайн-системы: **Palettes** (`12:12032`) и **Neutral** (`12:13263`) — сетки цветовых токенов (палитра не извлечена целиком из-за объёма ответа MCP, но сам факт наличия отдельной страницы токенов важен — стоит запросить её при детальной проработке цветовой системы).

Несовпадение состава нижнего меню между экранами (5 пунктов с FAB на "Главной" vs Главная/Дневник/Обучение/Питание/Профиль на "Дневнике"/"Обучении") подтверждает предупреждение пользователя: меню в макетах ещё не устоялось.

## Визуальный язык (по факту разбора экрана `794:563` через get_design_context)

- **Тема:** тёмная, фон `#0A0D12` с мягкими радиальными цветными свечениями (фиолетовое/зелёное) поверх.
- **Карточки:** фон `#272C35` (акцентные) и `#15181F` (нейтральные), скругление `24px`, паддинг `14px`, иногда `inset box-shadow` цветным свечением по смыслу метрики (зелёное — норма, красное — высокое).
- **Акцентный цвет:** лаймовый `#C9F14C` — FAB "добавить приём пищи", активный день недели, полоски прогресса шагов.
- **Тревожные/статусные цвета:** красный `#E94545`/`#B84244` — превышение сахара; зелёный `#869781`/оттенки — норма/низкий.
- **Текст:** основной `#F3F5F9`, приглушённый `#9299A5` / `rgba(243,245,249,0.45-0.65)` для подписей и вторичных значений.
- **Типографика:** заголовки — `Manrope SemiBold`; обычный текст/лейблы — `Manrope Regular`; числовые значения (метрики, суммы) — семейство `Outfit` (Regular/Medium/SemiBold), крупные цифры до `60px` для главного показателя (глюкоза), `42px` для калорий.
- **Навигация:** нижний бар с `backdrop-blur` и градиентной подложкой (`from #0A0D12 via rgba(10,13,18,0.85) to transparent`), пункты — иконка `lucide` 20px + подпись 12px, центральный пункт — крупная лаймовая FAB-кнопка 64px с мягкой цветной тенью.
- **Верхние "пилюли"** (уведомления, счётчик серии): `backdrop-blur`, `bg rgba(255,255,255,0.06)`, бордер `rgba(255,255,255,0.08)`, `rounded-999px`.
- **Графики:** кастомные бар-чарты (сахар по часам, тонкие капсулы `4px` шириной) и line-chart с точками-узлами (давление) — не стандартные библиотечные виджеты, а кастомная отрисовка.
- **Иконки:** предположительно `lucide` (судя по названиям слоёв `lucide/house`, `lucide/bell`, `lucide/drumstick`, `lucide/bean`, `lucide/wheat` и т.д.) — иконки должны экспортироваться из Figma как ассеты, не переизобретаться вручную.

## Рекомендации для gsd-ui-researcher

1. Считать этот файл отправной точкой, а не финальной спецификацией — состав экранов и навигации нужно уточнить с пользователем на этапе исследования (уже частично сделано выше, но финальный список экранов/пунктов меню должен подтвердить пользователь).
2. Извлечь и задокументировать точную цветовую палитру/токены из фреймов "Palettes"/"Neutral" отдельным запросом при детальной проработке (в этом брифе — не вытянуты целиком из-за объёма ответа MCP).
3. Сопоставить набор экранов макета (Главная/Дневник/Обучение/Питание/Профиль) с текущими маршрутами `app/app/(home)/...` и активными Requirements — часть текущих экранов может не иметь аналога в Figma и наоборот.
4. Кастомные графики (сахар, давление, кольцо калорий) — зафиксировать как компонentную задачу, а не переиспользование готовой чарт-библиотеки один-в-один.
