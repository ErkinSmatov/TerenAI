<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Наблюдатель → данные пациента | Детальный экран показывает чужие медицинские данные в режиме только для чтения |
| Пациент → код доступа | Код доступа на экране даёт возможность подключить наблюдателя |
| Клиент → Convex (`revokeLink`, `regenerateCode`) | Разрыв связи и ротация кода |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07.1-50 | Elevation of Privilege | Потеря пропа `readOnly` даёт наблюдателю действия над данными пациента | mitigate | План требует сохранить `readOnly` у всех сводок; приёмка сверяет число вхождений до и после и требует нулевого числа `useMutation` на детальном экране |
| T-07.1-51 | Tampering / IDOR | Ослабление клиентской стороны разрыва связи | mitigate | Проверка участия по обоим полям (`observerId`/`patientId`) реализована на сервере в Phase 6; клиент её не дублирует и не ослабляет. План запрещает трогать мутации, приёмка проверяет отсутствие удалённых `useMutation`/`useQuery` в диффе |
| T-07.1-52 | Information Disclosure | Код доступа выводится крупным шрифтом и может быть случайно заснят/показан | accept | Поведение идентично текущему (код и сейчас отображается на экране); фаза меняет только размер и шрифт. Ротация кода остаётся доступной пользователю |
| T-07.1-53 | Repudiation | Подмена формулировки деструктивного подтверждения на менее ясную вводит пользователя в заблуждение о последствиях | mitigate | Тексты берутся дословно из §Copywriting Contract, приёмка проверяет их грепом; существующая формулировка «Убрать из списка наблюдаемых» сохраняется, так как относится к другому действию |
| T-07.1-54 | Elevation of Privilege | Создание нового действия «Отозвать доступ» под видом применения копирайта | mitigate | План прямо запрещает создавать отсутствующее действие; при его отсутствии требуется фиксация факта в SUMMARY, а не реализация |
| T-07.1-SC | Tampering (supply chain) | Установка npm-пакетов | mitigate | План не добавляет зависимостей; приёмка фазы проверяет неизменность `package.json` |
</threat_model>
