разделом "Bottom Tab Bar — 5 Tabs" — обе версии оставлены в файле для

## 3. Блок профиля (`components/profile/ProfileHeader.tsx`)

Новый компонент, смонтирован первым дочерним элементом внутри
`SafeArea`/`ScrollView` экрана `app/app/(tabs)/settings.tsx`, выше
существующих `SettingsGroup`. Остальная функциональность экрана не
изменена. Внутристраничный `<Title>` обновлён "Настройки" → "Профиль" для
внутренней согласованности с новым лейблом вкладки.

**Явно пропущенный блок уровня/XP** (по прямому решению пользователя): в
Figma-узле есть подзаголовок "Уровень 7. Исследователь питания" и бар
"1830 XP / уровень 8" — в приложении нет системы уровней/опыта вообще, только
серия (streak) и бейджи, поэтому эта секция НЕ реализована.

### Карточка-контейнер

- Фон: тёмная тема — литеральный фиксированный `#0A0D12` (та же осознанная
  конвенция "декоративный figma-цвет, не через `getColor()`", что и у
  hero-карточек калорий/глюкозы; численно совпадает с токеном `background`
  тёмной темы, но задан буквально). Светлая тема — `getColor("base", ...)`
  (нет Figma-референса).
- `border-radius: 48px`, `padding: 20px`, `gap: 16px`.
- Свечение: переиспользован `lib/ui/getNutrientGlow.ts` (inset в тёмной теме,
  амбиентное в светлой). Тёмное значение — буквальный Figma `#73887b`
  (приглушённый шалфейный тон). **Светлое значение — собственный дизайн этой
  сессии, Figma-референса нет**: `rgba(115, 136, 123, 0.22)`.

### Ряд аватар+имя

- Круг 60×60, `backgroundColor: getColor("primary", undefined, theme)` —
  тема-зависимый акцентный токен (не Figma-литерал, т.к. это просто "цвет
  акцента").
- Первая буква имени, uppercase, `weight="700"`, цвет —
  `getColor("background", undefined, theme)`: намеренный повторный выбор
  токена `background` (не `foreground`) — в тёмной теме `background` почти
  чёрный (тёмный текст на светлом лайм-акценте), в светлой теме `background`
  почти белый (светлый текст на средне-синем акценте) — контраст работает
  правильно в обеих темах одним и тем же токеном.
- Имя — `useQuery(api.home.getCurrentUserName.default)`, тот же fallback
  ("Гость"), что уже установлен в `HomeHeader.tsx`.

### Ряд достижений (3 тайла)

- Данные: `useQuery(api.badges.listBadges.default)`, сортировка по
  `earnedAt` **по убыванию**, берутся первые 3 на клиенте. Если реальных
  бейджей меньше 3 — рендерится меньше тайлов (НЕ фабрикуются
  плейсхолдер-бейджи). Если бейджей 0 — единственная строка текста "Пока нет
  достижений" вместо 3 пустых боксов.
- Визуальное семейство — тот же плоский `#15181F`(тёмная)/`base`(светлая) +
  `lib/ui/getNutrientGlow.ts`, что и `HomeNutrientGlowCard`/
  `HomeGlucoseRangeTile`. Свечение — буквальный Figma `#313131` (нейтральный
  серый, НЕ насыщенный цвет, в отличие от нутриент-тайлов) для тёмной темы.
  **Светлое значение — собственный дизайн этой сессии**: `rgba(49, 49, 49,
  0.14)`.
- Содержимое тайла: иконка (`FlameIcon` для `type: "streak"`, `UtensilsIcon`
  для `type: "mealCount"` — те же иконки, что уже используются для этих
  понятий в `HomeHeader.tsx`) + реальное название бейджа из
  `findBadgeDefinition(badge.type, badge.threshold)` (НЕ Figma-плейсхолдер
  "2 карты" — тот текст относится к несвязанной, не строящейся Figma-демо
  фиче).
