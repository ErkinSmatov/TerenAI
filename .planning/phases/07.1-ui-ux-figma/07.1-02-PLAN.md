lib/ui/resolveFontFamily.ts:
- `export type FontFamilyName = "manrope" | "outfit"`
- `export default function resolveFontFamily(params: { weight?: TextStyle["fontWeight"]; style?: TextStyle["fontStyle"]; family?: FontFamilyName }): string`
- Возвращает одно из четырёх значений: `"Manrope_400Regular"`, `"Manrope_600SemiBold"`, `"Outfit_400Regular"`, `"Outfit_600SemiBold"`

components/ui/Text.tsx:
- `TextProps` расширяется полем `family?: FontFamilyName` со значением по умолчанию `"manrope"`
- Существующие props `size` (строковый enum `"10"…"48"`), `weight` (строковый enum `"100"…"900"`), `color` сохраняются без изменений сигнатуры

Типографические роли из UI-SPEC §Typography (использовать эти пары в экранных планах):
- Label/caption: Manrope, `size="12"`, `weight="400"`
- Body: Manrope, `size="16"`, `weight="400"`
- Heading / заголовок экрана: Manrope, `size="20"`, `weight="600"`
- Display (значение метрики): Outfit, `size="48"`, `weight="600"` — единственный display-размер; «герой» и вторичные числа различаются раскладкой и цветом, а не вторым размером

Ограничение источника: семейства Manrope и Outfit в Google Fonts не имеют курсивных начертаний. Объявленных весов ровно два на семейство (400 Regular, 600 SemiBold) — UI-SPEC явно запрещает вводить дополнительные.
