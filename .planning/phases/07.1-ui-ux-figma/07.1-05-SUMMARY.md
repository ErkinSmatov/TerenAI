## Decisions Made

- Заливка кольца прогресса в обеих карточках метрик переопределена по статусу (`ratio > 1` → `destructive`, иначе → `primary`/accent) вместо использования переданного `item.color` — прямая реализация must-have про акцентную заливку «в норме»; цвет иконки остался `item.color`, чтобы визуально различать макросы на иконках
- Каркас `HomeMacroSummary`/`HomeMicroSummary` не переписан под `SafeArea`/header-паттерн `HomeGlucoseSummary` — план прямо разрешает не трогать уже корректный каркас
- `WithSkeleton.tsx`/`Skeleton.tsx` не редактировались: цвет подложки уже резолвится в теле рендера `Skeleton.tsx` через `getColor()`, и родитель (`LogItem`) теперь вызывает `useThemeContext()`, значит скелетон корректно перерисовывается при переключении темы без прямой правки этих файлов
- Вертикальные интервалы приведены к шкале UI-SPEC: `HomeMacroSummary`/`HomeMicroSummary` container gap 12→16 (`md`), `HomeRecentlyLogged` itemsContainer gap 12→8 (`sm`)
