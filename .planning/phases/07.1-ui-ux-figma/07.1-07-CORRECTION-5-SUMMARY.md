## Accomplishments

### 1. Real meal photo wiring — `convex/meals/getWeekMeals.ts`

`meal.photoStorageId` was stored but never resolved to a usable URL anywhere in the app. The
query now maps every meal (across all 7 days) to `{ ...meal, photoUrl: string | null }`,
resolved via `ctx.storage.getUrl(meal.photoStorageId)` when set, through a nested `Promise.all`
to avoid serial awaits. This is purely additive — `MealCompletionWatcher.tsx`,
`app/(home)/nutrients.tsx`, and `app/(tabs)/index.tsx` (all existing consumers of this same
query) needed no changes and still compile cleanly, since none does an exact/strict shape check
on the meal objects.

### 2. "Недавно добавлено" redesign — `components/home/HomeRecentlyLogged.tsx` (rewritten)

Replaced the vertical full-width list with a horizontal `ScrollView` of fixed `169×160`px cards
(Figma node `840:5483`), each built from the existing themed `Card` component (not a
special-cased fixed-hex surface — Figma's `#272C35` for this card is identical to the project's
dark `base` token). Per card: a 60×60 circular photo thumbnail (`expo-image`, `contentFit`
`"cover"`, falls back to a centered `UtensilsCrossedIcon` when `photoUrl` is absent) wrapped in
a real, data-driven 3-segment `CircularProgress` ring (carbs/protein/fat ratios for that meal
specifically, against the daily calorie target — reusing `HomeDaySelector`'s exact technique,
not the raw Figma export's fixed-angle decorative ellipses), the `HH:mm` time label beside it,
the dish name below (with `WithSkeleton` while processing), and a protein/carbs/fat macro badge
row (existing `ProteinIcon`/`CarbIcon` reused, plain `DropletIcon` for fat per user preference —
see key-decisions). The calorie badge from the old vertical list is dropped, matching Figma.
`app/(home)/day/[date].tsx` (Дневник, untouched, future wave) still passes meals without
`photoUrl` from a different month-scoped query — its cards simply show the fallback icon, which
is expected, not a defect; the meal prop type (`Doc<"meals"> & { photoUrl?: string | null }`)
accepts both shapes.

### 3. Calorie ring end-cap clipping fix — `components/ui/CircularProgress.tsx`

Root cause: the Skia `<Canvas>` was sized to exactly the ring's reported layout box, and the
optional `endCap` "handle" dot pokes `endCap.radius - strokeWidth/2` px past the stroke's own
outer edge, which already touches that box's boundary — Skia clips Canvas contents to its pixel
bounds, cutting off the top of the dot. Fixed by computing `overflow = max(0, endCap.radius -
strokeWidth/2)` and rendering the actual Canvas `overflow*2` larger, absolutely positioned and
centered via `top/left: -overflow`, without changing the component's reported layout size (so
`HomeCalorieOverviewCard.tsx`'s `ringColumn` flex layout is unaffected). The circle path center
and `Group` rotation origin shift by `+overflow` to stay centered in the enlarged canvas. When no
`endCap` is passed (`HomeDaySelector.tsx` and any other caller), `overflow` is exactly `0` and
all the new math collapses to the original positions — confirmed by inspection, no visual
regression for existing callers.

### 4. Activity bar sizing — `components/home/HomeCalorieOverviewCard.tsx`

`stepsBlock.paddingHorizontal`: `16` → `28` (narrower bar). `trackHeight`/`fillHeight` on the
steps `ProgressBar`: `3` → `6` (thicker, closer to — without matching exactly — the macro bars'
`9`/`5` proportions). Both are visual-judgement values; no numeric spec was given.

### 5. Sport-shoe icon — `components/icons/SportShoeIcon.tsx` (new)

No `lucide-react-native` icon matches the Figma layer "lucide/sport-shoe" (verified against the
installed `lucide-react-native@0.543.0` package — no such icon exists; `FootprintsIcon` was
previously used as a placeholder). New custom `react-native-svg` component built from the exact
path data exported from Figma (node `863:5405`), following the project's `size`/`color` icon
prop convention (`Dot1Icon.tsx`). Kept the Figma export's own `20×20` viewBox and `1.66667`
default `strokeWidth` rather than rescaling to lucide's `24×24`/`2` convention, so the line
weight matches the export exactly. Swapped in for `FootprintsIcon` in the steps row.

### 6. Header logo removal + darker blur — `components/home/HomeHeader.tsx`

Removed the `TerenAILogo` icon before "TerenAI" (text-only wordmark). Added a semi-transparent
blurred background reusing the bottom tab bar's exact `BlurView` technique
(`app/(tabs)/_layout.tsx`), but darker/more opaque per explicit request: `intensity={45}` (vs
the tab bar's `30`) plus an additional `getColor("background", 0.15, theme)` scrim `View`
layered on top of the blur. Background is a rounded bar (`borderRadius: 24`, the project's `Card`
radius convention) with `overflow: hidden` on the `SafeArea` container so the blur/scrim respect
the rounded corners; renders as the first two children so existing logo/icon-group content stays
on top in z-order.

### 7. `.planning/phases/07.1-ui-ux-figma/07.1-UI-SPEC.md`

Added a new "Home — Recently Logged, Calorie Ring, Activity Bar, Header (5th D-03 correction
round, 2026-09-22)" section documenting the card contract, the ring-clipping fix and its math,
the activity bar dimensions, the new icon, and the header's blur/scrim treatment — same
documentation style as the four prior correction sections.
