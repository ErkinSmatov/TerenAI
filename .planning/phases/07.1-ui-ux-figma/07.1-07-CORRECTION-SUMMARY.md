# Phase 07.1 Plan 07 Correction: Merged Calorie Overview Card (D-03 checkpoint) Summary

**Replaced the 3-block Главная layout (calorie ring card + row of 3 macro tiles + standalone movement card) with one merged card matching Figma node 863:5405, per user feedback at the D-03 human-verification checkpoint.**

## Context

This is not a new phase or an out-of-scope deviation — it is a scope correction requested
directly by the user during the mandatory D-03 checkpoint for wave "Главная". The user
compared the running app against Figma node `863:5405` and asked for the calorie ring, the
three macro tiles, and the standalone movement/steps card to be merged into one card. Three
clarifying questions were asked and answered before this work started:

1. Light theme needs its own gradient variant, not a reuse of the dark gradient.
2. The standalone movement/steps card is removed from the Home screen only; its steps/km
   data moves inside the new merged card.
3. The micronutrients card (fiber/sugar/sodium, `HomeMicroSummary.tsx`) is untouched.

## Setup Note: Stale Worktree Base

Before any code changes, the worktree's branch (`worktree-agent-aef1f2be714eddd77`) was found
to be based on a commit (`639c9eb`) six days behind `main`'s current tip (`dddfb44`) — missing
all 42 commits of phase 07.1 waves 1–3 (the entire dark-theme foundation, font migration, and
theme-aware Home components this correction depends on). The working tree was clean and
`639c9eb` was confirmed to be a strict ancestor of `main`'s tip (no divergent commits), so the
branch was fast-forwarded with `git reset --hard main` before proceeding — a safe, lossless
sync, not a destructive rewrite. Flagging this here in case the worktree provisioning step
that spawned this agent needs investigation (it should have branched from `main`'s tip, not
from an earlier point).

## Accomplishments

- **`HomeCalorieOverviewCard.tsx`** (new): single card with a gradient background (dark:
  literal Figma gradient `rgb(192,91,23)` → `rgb(27,27,27)`; light: bespoke `orange`-tinted
  variant), a reused `CircularProgress` ring showing calories remaining (target − consumed,
  can go negative) in its center, three macro rows in Figma order (Белки, Жиры, Углеводы)
  each with a horizontal rounded progress bar in the macro's existing semantic color, and a
  bottom row (Всего / steps+distance / Съедено).
- Macro bar colors reuse the existing `protein`/`fat`/`carb` tokens (not Figma's decorative
  gradient colors). The calorie ring and steps bar use the accent token per UI-SPEC's
  existing reserved-for-accent contract, falling back to `destructive` over target.
- Steps indicator reuses `FootprintsIcon` (same icon `HomeMovementSummary` already used) and
  a fixed 10000-step default goal for its progress ratio (no per-user config exists).
- `HomeMacroSummary.tsx` now renders this single card instead of `HomeSummaryCardBig` + a row
  of three `HomeSummaryCard`, reordering macros to the Figma-specified sequence, and forwards
  a new optional `movement` prop.
- `app/app/(tabs)/index.tsx` passes `movement={dayMovement}` into `HomeMacroSummary` and no
  longer renders a standalone `HomeMovementSummary` block (import removed).
- `.planning/phases/07.1-ui-ux-figma/07.1-UI-SPEC.md` gained a new "Home — Calorie Overview
  Card" section documenting this card's contract retroactively, since it wasn't captured when
  the rest of the spec was written.

- **Verification:** `npx tsc --noEmit` clean project-wide, including both untouched call sites
