## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Cron → база данных | Проверки читают профили и токены всех пользователей и пишут метки отправки |
| Сохранённое `timezoneOffsetMinutes` → решение об отправке | Значение изначально пришло с клиента и определяет момент отправки push |
| Проверка → Expo Push API | Через запланированный internal-action уходит рассылка |
