**User's choice:** Push-уведомление, повторяется каждые 7 дней от последнего ввода веса (не разовое).

Дополнительные решения в этой области:
- Сейчас вес обновляется только через полный 12-шаговый экран пересчёта целей (`generateMacroTargets.tsx`) → выбран **новый лёгкий экран «только вес»**, а не редирект в существующий поток.
- После ввода нового веса цели по калориям/БЖУ пересчитываются **автоматически**, без запроса подтверждения.
- Момент показа системного запроса push-разрешения (iOS) — **на усмотрение исполнителя**.
- Тап по push-уведомлению → **сразу лёгкий экран «только вес»** (не главный экран).
- Напоминание можно **отключить в Настройках** (отдельный тумблер).

**User's choice:** Несколько фиксированных точек (завтрак/обед/ужин).

Дополнительные решения:
- Если к моменту точки блюдо уже записано — push для этой точки **пропускается**.
- Точное время точек — **на усмотрение исполнителя**.
- Текст push **учитывает стрик/геймификацию** (не нейтральный текст).
- **Отдельный тумблер** в Настройках, независимый от тумблера напоминания о взвешивании.

## Геймификация: направление

| Option | Description | Selected |
|--------|-------------|----------|
| Стрики + бейджи | Расширяет существующий стрик, добавляет достижения за вехи | ✓ |
| Очки + уровни | Новая система начисления очков, самая большая новая система с нуля | |
| Социальный формат через наблюдателей | Сравнение стриков/активности между наблюдаемыми | |
| Комбинация направлений | Не одно направление | |

**User's choice:** Стрики + бейджи.

Дополнительные решения:
- Источники бейджей: **вехи стрика** (7/30/100 дней) **и** **количество записанных блюд** (10/50/100 приёмов) — оба источника.
- Витрина бейджей — **новый экран из Профиль/Настройки**.
- Получение бейджа → **моментальное празднование** (не просто появление в витрине постфактум).
- Побочный вопрос: иконка стрика в шапке (пламя+число) сейчас по факту ведёт на экран наблюдаемых (Phase 6), а не про сам стрик. Пользователь дал развёрнутый ответ: календарь на дате отмечает **все дни с хотя бы одним записанным блюдом**, тап по дате ведёт на аналитику дня (переиспользует Phase 68 HIST-01/02), и в итоге — **объединить существующий экран календаря (Phase 68) со стрик-экраном** в один. Финальная раскладка шапки: кнопка-календарь удаляется, кнопка-стрик теперь ведёт на объединённый экран (стрик сверху + календарь снизу), добавляется новая отдельная кнопка для перехода на список наблюдаемых.
