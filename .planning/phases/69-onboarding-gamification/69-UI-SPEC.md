### New primitive required: `SettingsToggleItem`

No `Switch` or toggle component exists anywhere in `components/` today (confirmed by grep — zero matches). This phase needs two independent toggles (D-09, D-14). Build one new component:

- Base: React Native's built-in `Switch`, restyled with `getColor()` tokens — not a new animated primitive from scratch, not a third-party toggle library (none needed for a binary on/off control).
- Track colors: off = `getColor("muted")` (#f3f4f6), on = `getColor("primary")` (#3B82F6) — reuses the existing accent-blue convention (see Color section).
- Thumb: `getColor("base")` (#ffffff) in both states.
- Layout: same row shape as `SettingsItem` (icon + label, 52px height, 16px horizontal padding) with the toggle right-aligned instead of a chevron/nothing.
- Must NOT navigate on row press — only the toggle control itself is interactive (avoid accidental double-tap-to-toggle from tapping the label).

## Spacing Scale

Declared values (project's existing scale — verified from `Card`, `Button`, `SettingsItem`, `HomeHeader` styles; all multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-text gaps inside pills (streak pill `gap: 2` rounds to this tier) |
| sm | 8px | Compact gaps — `HomeHeader.iconGroup` gap, toggle row internal gaps |
| md | 16px | Default element spacing — `SettingsItem` horizontal padding, `HomeHeader` bottom margin, screen horizontal gutters |
| card | 20px | Card internal padding (`Card.tsx` — project's actual default, not the generic 24px "lg" token) |
| lg | 24px | Section padding between stacked blocks on new screens (e.g. gap between `StreakHeader` and calendar on the combined screen) |
| xl | 32px | Layout gaps — vertical gap above/below the badge celebration modal content |
| 2xl | 48px | Major section breaks — not used in this phase's new screens |

**Exceptions:**
- Icon-only header buttons (streak pill, new `observedList` pill, calendar's old pill) keep the existing 44×44px minimum touch target (`HomeHeader.streakContainer`/`calendarContainer` precedent) — below the 48px iOS HIG ideal but matches the established project convention, do not deviate.
- `Card` padding is 20px project-wide, not the generic 24px token — followed as-is for all new Card-based surfaces (badge tiles, weigh-in screen card, celebration modal card) for visual consistency.

## Typography

Declared for **new UI in this phase only** (existing reused components like `SettingsItem` keep their own established weight-500 label style unchanged):

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 (regular) | 1.5 |
| Label | 14px | 400 (regular) | 1.4 |
| Heading | 20px | 600 (semibold) | 1.2 |
| Display | 40px | 600 (semibold) | 1.1 |

- **Body 16/400** — helper/explainer text: weigh-in screen recalculation notice, toggle row captions, badge tile description text.
- **Label 14/400** — secondary/meta text: badge earned date, "X дней подряд" threshold captions, push toggle sub-label.
- **Heading 20/600** — screen section titles: matches the existing `EmptyState` heading precedent in `app/app/(home)/day/[date].tsx` ("Нет данных за этот день" is 20/600) — reused verbatim for "Достижения", "Пока нет достижений", celebration modal title "Новое достижение!".
- **Display 40/600** — the streak count number on the combined screen, matching `components/home/HomeSummaryCardBig.tsx`'s existing big-number convention (`size="40" weight="600"`) — do not introduce a new display size.

Only 2 weights used in this phase's new text: 400 and 600. (Existing `SettingsItem` at weight 500 is reused unmodified, not part of this phase's new typography set.)

Font component: use `components/ui/Text.tsx` / `components/ui/Title.tsx` exclusively — `size` prop takes the string enum (`"14"`, `"16"`, `"20"`, `"40"`), never a raw number.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `getColor("background")` `#f9fafb` | Screen backgrounds — weigh-in screen, streak+calendar screen, badge showcase screen, notification settings screen |
| Secondary (30%) | `getColor("base")` `#ffffff` | Card surfaces — `SettingsGroup` toggle rows, badge tiles, calendar card wrapper, celebration modal card |
| Accent (10%) | `getColor("primary")` `#3B82F6` | Reserved for: weigh-in screen primary CTA ("Сохранить вес"), `WeightPicker` indicator/highlight line (already this color in the existing component — unchanged), `SettingsToggleItem` track when ON, celebration modal primary "Круто" button |
| Gamification accent | `getColor("orange")` `#f97316` | Reserved for: streak flame icon (unchanged from `HomeHeader`), streak count `Display` text on the combined screen, earned-badge tile icon/border glow, celebration modal's celebratory visual accent (confetti-substitute animation color) |
| Destructive | `getColor("destructive")` `#ef4444` | Not used — no destructive actions introduced in this phase's new UI (see Copywriting Contract) |

Accent reserved for (explicit, never "all interactive elements"): primary CTA buttons, active/ON toggle track, `WeightPicker` selection indicator, celebration modal confirm button — blue. Streak number, flame icon, badge-earned states, celebration accent — orange (the project's pre-existing, dedicated gamification color, do not introduce a third accent).
