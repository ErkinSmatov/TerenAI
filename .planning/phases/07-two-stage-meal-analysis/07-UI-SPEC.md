## Ingredient Row — Exact Spec

Modeled on `components/meal/MealItems.tsx`'s existing `Card` row (`styles.card`: `flexDirection: row`, `justifyContent: space-between`, `alignItems: center`, `padding: 16`, `gap: 20`), extended for edit affordances:

```
[ name (flex:1, 16px/400, editable inline) ]  [ ✕ 44×44 ]
[                                            ]
[ − 44×44 ]  [ grams value 16px/600, tap-to-edit ]  [ + 44×44 ]
```
(Exact row layout — single line if space allows, two-line if not — is planner/executor's call; the token values below are locked regardless of layout.)

- Row container: `Card` (existing `card` token: `padding: 20` default, but MealItems.tsx overrides to `padding: 16` for compact list rows — use the `padding: 16` override here too, `gap: 20` between name-block and controls)
- Row gap in list: `8px` (matches `MealItems.tsx` `ingredientsContainer: { gap: 8 }`)
- Name text: `16px / weight 400 / color foreground`
- Grams value text: `16px / weight 600 / color foreground` (bumped from `MealItems.tsx`'s read-only `14px/500` because this is now an editable, tappable, primary-interaction value — larger touch target and stronger weight signal "tap me")
- Stepper buttons: `44×44pt` minimum touch target (accessibility exception to the 8-pt spacing scale — icon glyph itself stays `16px`, padding absorbs the difference), `Button variant="base"`
- Remove control (`✕` or swipe): `destructive` red (`getColor("red")`) on the icon only; row background does NOT turn red at rest — red only appears as the swipe-reveal background or the `✕` icon color, matching the existing muted-icon-until-action convention (`ObservedPatientCard.tsx`'s `WarningBadge` pattern: color reserved for the specific warning glyph, not full-row tinting)

## Error State (Meal.tsx) — Exact Spec

Sibling branch to `loading`/`done`, rendered inside `ScreenMainScrollView` (same scaffold as the `done` state, so header/footer chrome doesn't jump):

- Icon: `TriangleAlertIcon` (already used for warnings in `components/observer/ObservedPatientCard.tsx`), `size 48`, `color getColor("red")`
- Heading: `18px / weight 600 / color foreground` — copy: `"Не удалось распознать блюдо"`
- Body: `14px / weight 400 / color mutedForeground` — copy: `"Что-то пошло не так при обработке. Попробуйте ещё раз."`
- Spacing: `24px` gap between icon and heading block (matches `2xl`-adjacent section-break scale), `8px` between heading and body (matches `sm` token)
- CTA: `ScreenFooterButton` "Повторить" (see Screen & Component Inventory table above) — becomes `disabled` + label swaps to `"Повторяем…"` while the retry mutation is in flight (mirrors the existing `isCorrecting` disabled/label-swap pattern in `fix-meal.tsx:88-98`)
- If the phase-7 light retry rate limit (D-18, open question A1 in RESEARCH.md — confirm at planning time whether in scope) is hit: `Toast.show({ text: "Слишком много попыток. Попробуйте позже.", variant: "error" })`, same as the existing `"Вы достигли дневного лимита функций ИИ."` pattern used everywhere else in this codebase for rate-limit feedback

## Spacing Scale

Declared values (must be multiples of 4) — these are the app-wide tokens; this phase reuses them as-is, does not introduce new ones:

| Token | Value | Usage in this phase |
|-------|-------|-------|
| xs | 4px | Icon-to-text gaps (e.g. inside the add-ingredient row's icon+label) |
| sm | 8px | Ingredient list row-to-row gap; error-state heading-to-body gap |
| md | 16px | Card row padding; `SafeArea` horizontal padding; `ScreenMainTitle` bottom padding |
| lg | 24px | Photo-preview-to-ingredient-list section gap; error-state icon-to-heading gap |
| xl | 32px | Scroll content bottom padding (`ScreenMainScrollView`'s existing `paddingBottom: 24`–`32` convention) |
| 2xl | 48px | Not used on this screen (declared for completeness/global consistency) |
| 3xl | 64px | Not used on this screen |

Exceptions:
- `12px` — section header row bottom padding (`"Ингредиенты"` label to list), matches existing `MealItems.tsx:headerContainer` precedent exactly
- `20px` — inner row gap between name-block and controls in each ingredient `Card`, matches existing `MealItems.tsx:card` precedent exactly
- `44×44pt` — minimum touch target for the grams stepper `±` buttons and the `✕` remove button (accessibility floor, not a spacing-scale value — the icon glyph stays 14–18px, surrounding hit area is padded to 44pt)

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 | 1.5 |
| Label | 14px | 400 | 1.3 |
| Heading | 18px | 600 | 1.2 |
| Display | 22px | 600 | 1.2 |

Element-to-role mapping for this phase (2 weights total — 400 regular, 600 semibold — no third weight introduced):
- Screen title ("Проверьте блюдо", in `ScreenHeaderTitle`) → **Heading** (18/600) — reused unchanged from `ScreenHeader.tsx`
- Page heading ("Что вы съели?"-equivalent, in `ScreenMainTitle` if used) → **Display** (22/600) — reused unchanged from `ScreenMain.tsx`
- Ingredient name (inline-editable) → **Body** (16/400)
- Grams numeric value (tap-to-edit) → 16px but **weight 600** (borrows Heading's weight at Body's size — deliberate: signals "primary editable value," stays within the 2-weight budget)
- Description/body copy (empty-list helper text, error-state body) → **Label** (14/400)
- Error-state heading → **Heading** (18/600)
