<feature>
  <name>Автомат статусов связи наблюдателя</name>
  <files>lib/observers/linkStatus.ts, scripts/verifyLinkStatus.ts, package.json</files>
  <behavior>
    Таблица переходов resolveTransition (всё, что не перечислено, даёт noop; неверная роль даёт forbidden):
    - request, actor observer: null → apply pending; expired → apply pending; revoked → apply pending; declined и now - respondedAt меньше DECLINE_COOLDOWN_MS → cooldown; declined и прошло не меньше DECLINE_COOLDOWN_MS (или respondedAt не задан) → apply pending; pending → noop; active → noop. request с actor patient или system → forbidden.
    - accept, actor patient: pending → apply active; иначе noop. accept с actor observer или system → forbidden.
    - decline, actor patient: pending → apply declined; иначе noop. Другие роли → forbidden.
    - revoke, actor patient или observer: active → apply revoked; иначе noop. actor system → forbidden.
    - cancel, actor observer: pending → apply revoked (допущение A6: отмена хранится как revoked с endedBy observer, новый статус не вводится); иначе noop. actor patient или system → forbidden.
    - expire, actor system: pending → apply expired; иначе noop. Другие роли → forbidden.
    Остальные функции:
    - normalizeLinkStatus(undefined) === "active"; normalizeLinkStatus("pending") === "pending".
    - isActiveLink({status:"active"}) true; {} true (legacy до миграции); "pending", "declined", "revoked", "expired" — false.
    - pickEffectiveLink([]) === null; приоритет active > pending > declined > revoked > expired (по normalizeLinkStatus); при равном статусе выигрывает строка с большим (requestedAt ?? _creationTime). Пример: [revoked t=5, active t=1] → active; [declined respondedAt, pending] → pending.
    - isPendingExpired(requestedAt, now): true, когда now - requestedAt >= PENDING_EXPIRY_MS; ровно на 1 мс раньше — false.
    - shouldNotifyRequest(undefined, now) true; (now - REQUEST_PUSH_DEDUP_MS + 1, now) false; (now - REQUEST_PUSH_DEDUP_MS, now) true.
    - resolveDoctorBadge(null) null; ({status:"pending", clinic:"X"}) null; ({status:"verified", clinic:"Клиника"}) → {clinic:"Клиника"}; verified с пустой или пробельной клиникой → null.
  </behavior>
  <implementation>
    Модуль без импортов из convex и без Date.now() внутри: время приходит аргументом now. Константы считать как 14 * 24 * 60 * 60 * 1000 и 24 * 60 * 60 * 1000. Таблицу переходов держать как явный switch по action с проверкой роли первой строкой ветки. Комментарии по-русски, со ссылками на D-08, D-09, D-10, D-11 и допущение A6.
  </implementation>
</feature>
