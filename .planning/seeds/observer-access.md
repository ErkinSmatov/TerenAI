## Идея

Наблюдатель за пользователем приложения — один функциональный тип роли, независимо от того, как пользователь обозначает связь: «родитель» (взрослый ребёнок присматривает за пожилым родителем), «врач» (наблюдает за пациентом) или «родитель» (в классическом смысле — присматривает за ребёнком). Права доступа одинаковы для всех трёх — это просто ярлык связи, не разный набор permissions.

## Обсуждённый скоуп (2026-08-14)

**Привязка наблюдателя:**
- Пациент (наблюдаемый) генерирует код в приложении и передаёт его наблюдателю (не наоборот — наблюдатель не ищет пациента)

**UI входа:**
- Кнопка в шапке приложения рядом с иконкой streak/огонька
- При нажатии — список наблюдаемых пользователей

**Карточка наблюдаемого в списке:**
- Глюкоза, количество приёмов пищи, калории, шаги (если есть)
- Только данные за сегодня, не полная история
- Визуальное предупреждение прямо на карточке при превышении калорий или сахара

**Детальный вид:**
- Клик по карточке наблюдаемого → тот же детальный вид, что на главном экране владельца данных

**Уведомления о нарушениях режима (список открыт для расширения):**
- Пропущен приём пищи к ожидаемому времени
- Глюкоза вышла за целевой диапазон
- Не залогировано ни одного блюда за день
- Пропущено измерение давления

**Push — сознательно отложен:**
- Первая версия: предупреждения видны только когда наблюдатель сам открывает список наблюдаемых (бейджи/варнинги на карточках)
- Push-уведомления (даже когда наблюдатель не открыл приложение) — нужны позже, отдельным куском работы. См. связанный research question про push-инфраструктуру.

## Открытые вопросы (не обсуждались, всплывут при discuss-phase)

- Множественность: может ли у одного пользователя быть несколько наблюдателей? Может ли один наблюдатель (например, врач) наблюдать за несколькими пациентами?
- Отзыв доступа: может ли пользователь в любой момент отозвать код/доступ наблюдателя?
- Согласие/приватность: считается ли передача кода достаточным согласием, или нужен доп. флоу подтверждения?
- Жизненный цикл кода: одноразовый, с истечением срока, перегенерируемый?
- Нужен ли наблюдателю собственный аккаунт в приложении, или отдельный облегчённый вход/портал без полноценной регистрации?
