## Push-уведомления для Expo/React Native

**Поднято:** 2026-08-14, во время `/gsd-explore` по фиче «Observer access» ([[observer-access]] seed)

**Вопрос:** Какая инфраструктура нужна для push-уведомлений в проекте — провайдер (Expo Push Service поверх FCM/APNs, или прямая интеграция FCM/APNs), регистрация и хранение device token per пользователь, разрешения на устройстве (iOS/Android), доставка события из Convex (какой backend-триггер шлёт push).

**Зачем:** Первая версия фичи «Observer access» (наблюдатель за родителем/ребёнком/пациентом) сознательно ограничена UI-предупреждениями — уведомления о нарушениях режима видны только когда наблюдатель сам открывает список наблюдаемых. Push (уведомление приходит, даже если наблюдатель не открыл приложение) нужен следующим шагом, но в проекте сейчас push-инфраструктуры нет вообще.

**Статус:** Не исследовано.
